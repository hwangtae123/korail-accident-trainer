# 화면 명세

사용자: 기술교육센터 교관(보고서 올리기, 시나리오 검수·편집), 교육생(판단 훈련), 현장 작업책임자(작업 전 브리핑).
이전 버전 화면 `docs/reference-ui/legacy-index.html`을 브라우저로 열어 보면 흐름을 알 수 있다(백엔드 없이 열면 데이터는 안 나옴).

## 레이아웃
- 상단 바: 서비스 이름 "사고사례 판단 훈련".
- 왼쪽: ① PDF 올리기(여러 개 가능) ② 유사사고 검색 입력 ③ 보고서 목록(새로 접수된 순; 제목, 보고서 번호, 발생 일시, 접수 시각, 유형 태그, 상태 태그) ④ "반복 패턴", "작업 전 브리핑" 메뉴.
- 오른쪽: 선택한 화면. 좁은 화면(900px 이하)에서는 위아래로 쌓는다.

## 1. 보고서 상세 (FE-2, FE-3, FE-4)
- 머리: 제목, `보고서번호 · 발생일시 · 장소`, 유형·차량 태그, "원문 PDF" 링크, 탭 [사고 정보 | 판단 훈련].
- 처리 중이면 현재 단계 이름(파싱/구조화/색인/시나리오)과 메시지. `ocr_needed`는 "텍스트를 읽을 수 없는 PDF(OCR 필요), LLM 호출 없이 건너뜀", `error`는 메시지 그대로.

**사고 정보 탭**
- 맨 위 카드 "비슷한 과거 사고": `GET /related` 3건. 각 건마다 제목(누르면 그 보고서로 이동), 유형·일시, 유사도, `shared_rules`가 있으면 빨간 태그 "이번에도 반복된 규정" + 규정 이름들, 맞은 조각 3개(종류 태그 + 160자 + p.N).
  - 버튼 "공통점 요약 (LLM)" → `POST /compare`. 결과 위에 "검색된 과거 사고 조각만 근거로 LLM이 쓴 요약, 원문과 대조" 안내.
- 안내 띠: "모든 항목은 LLM이 추출한 결과. p.N을 눌러 원문과 대조".
- 섹션: 개요 / 사고 경위(시각 굵게) / 직접 원인 / 기여요인 / 지적된 규정·지침(이름 굵게 + 조항 + 설명) / 안전권고(대상 태그) / 교육·훈련 관련 지적. 비어 있으면 "보고서에서 찾지 못함".
- 각 항목 끝에 `p.N` 링크(새 탭, `#page=N`)와 원문 구절. `evidence.verified`: true면 ✓ 원문 확인, false면 ⚠ 원문에서 못 찾음, null이면 표시 없음.

**판단 훈련 탭**
- 위: 검수 상태 태그(검수 전 = 주황, 검수 완료 = 초록), 역할 태그, 버튼 [시나리오 편집] [다시 생성] [검수 완료 표시]. 검수 전이면 "교관 검수 전 초안" 안내.
- 시작 화면: 제목, 도입 상황, 판단 지점 수, [훈련 시작].
- 단계: "판단 지점 n / N", 상황 박스, 질문, 선택지 버튼. 고르면 정답 초록·오답 빨강, 해설, 근거 규정 태그, "실제 사고에서는" + p.N, [다음]. 답한 뒤 선택지 글자는 흐려지지 않게.
- 결과: 점수, 마무리(debrief), [처음부터] [사고 정보 보기].
- 시나리오 편집(FE-4): 도입·역할·각 단계(상황, 질문, 선택지 추가/삭제, 정답 선택, 해설, 근거 규정, 실제 결과)를 고치고 저장(`PUT`). 저장하면 검수 상태가 "검수 전"으로 돌아간다고 미리 알린다. 501이면 저장 버튼을 막고 "준비 중".

## 2. 유사사고 검색 (FE-5)
- 입력 예시: "야간 선로 작업 중 인접선 열차 진입". `POST /search` 결과를 보고서별 카드(제목, 유사도, 맞은 조각 + p.N).
- [검색 결과로 요약하기 (LLM)] → `POST /ask`, 대조 안내 포함.

## 3. 작업 전 브리핑 TBM (FE-6)
- 입력: 오늘 작업(장소, 작업 종류, 장비). `POST /briefing`.
- 출력: 작업 설명, 과거 사고 요약, 확인 항목 체크리스트(체크박스 + 출처 보고서 + p.N), 비슷한 사고 목록.
- [인쇄] 버튼 → A4 한 장 인쇄용 화면(`@media print`: 메뉴 숨김, 체크박스는 빈 네모, 하단에 "출처: 사조위 사고조사보고서, LLM 요약 — 원문 대조 필요").
- 501이면 "준비 중".

## 4. 반복 패턴 (FE-7)
- `GET /stats`: 보고서 수, 사고 유형별 건수, 지적된 규정 상위 20개(건수 막대), 교육·훈련 관련 지적 목록(보고서로 이동 링크).

## 공통
- 로딩, 빈 목록, 501, 네트워크 오류 상태를 모두 화면에 표시한다(빈 화면 금지).
- 색: 남색 머리(#12305e), 강조 파랑(#1f5fbf), 확인 초록, 경고 주황, 오류 빨강. 폰트는 시스템 한글 폰트.
- 시연 흐름: 7건을 미리 넣고 → 1건을 화면에서 올림 → 단계 표시 → 끝나면 비슷한 과거 사고와 반복된 규정이 뜸 → 공통점 요약 → 판단 훈련.
